# Calculate-the-perimeter-of-the-circle
📖 Overview

This repository contains a collection of Python programming exercises demonstrating fundamental programming concepts such as mathematical calculations, functions, conditional statements, loops, file handling, and basic statistics.

The programs were developed as part of Python programming practice and cover a variety of beginner to intermediate-level problems.

📂 Contents

The repository includes solutions for the following exercises:

1. Circle Area and Perimeter
Accepts the radius of a circle from the user.
Calculates:
Area using π × r²
Perimeter (Circumference) using 2 × π × r
2. Sum of Arbitrary Numbers
Uses Python's *args.
Accepts any number of arguments.
Returns the total sum.
3. Celsius to Fahrenheit Converter
Converts temperature from Celsius (°C) to Fahrenheit (°F).
Formula used:
°F = (°C × 9/5) + 32
4. Season Checker

Determines the season based on the entered month and date.

Possible outputs:

Winter
Spring
Summer
Autumn
5. Calculate Slope

Calculates the slope of a linear equation using NumPy arrays.

6. Quadratic Equation Solver

Solves quadratic equations of the form:

ax² + bx + c = 0

Handles:

Two real roots
One repeated root
Complex roots
7. Print List

Prints every element of a list.

8. Reverse List

Returns the reverse of a list using loops.

Example:

Input:
[1,2,3,4,5]

Output:
[5,4,3,2,1]
9. Capitalize List Items

Converts every string in a list into uppercase.

10. Add Item to List

Adds a new item to the end of a list.

11. Remove Item from List

Removes a specified element from a list.

12. Sum of Odd Numbers

Calculates the sum of all odd numbers within a specified range.

13. Sum of Even Numbers

Calculates the sum of all even numbers within a specified range.

14. Check Empty List

Checks whether a list is empty or not.

15. Statistical Functions

Implementation of common statistical calculations including:

Mean
Median
Mode
Range
Variance
Standard Deviation
16. Count Number of Lines in a File

Reads a text file and counts the total number of lines.

17. Read File into a List

Reads every line of a text file and stores it in a Python list.

18. Remove Newline Characters

Removes newline (\n) characters from text.

19. Copy File Contents

Copies the contents of one file into another file.

20. Combine Two Files Line by Line

Reads two text files simultaneously and combines corresponding lines.
